# Backup Script Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Write `scripts/backup.sh` — a bash script that the systemd `crypto-trader-backup` timer calls nightly to create timestamped backups of the SQLite DB and JSONL trade journal, retaining only the last 7 days.

**Architecture:** Single self-contained bash script; reads `CT_ARTIFACTS_ROOT` from the environment (defaulting to `/var/lib/crypto-trader/artifacts`), writes timestamped copies to `/var/lib/crypto-trader/backups/`, uses `sqlite3 .backup` for an atomic online DB copy, then prunes backup files older than 7 days. All output goes to stdout so systemd/journalctl captures it.

**Tech Stack:** bash, sqlite3

- [ ] **Step 1: Write `scripts/backup.sh`**

Write the file at `/home/wdsr88/workspace/crypto-trader/scripts/backup.sh`:

```bash
#!/usr/bin/env bash
# scripts/backup.sh — nightly backup for crypto-trader
# Called by: /etc/systemd/system/crypto-trader-backup.service
# Runs as:   crypto user
# Output:    stdout → journalctl (SyslogIdentifier=crypto-trader-backup)
set -euo pipefail

# ── Config ────────────────────────────────────────────────────────────────────
ARTIFACTS_ROOT="${CT_ARTIFACTS_ROOT:-/var/lib/crypto-trader/artifacts}"
BACKUP_DIR="/var/lib/crypto-trader/backups"
RETAIN_DAYS=7

DB_SRC="${ARTIFACTS_ROOT}/paper-trades.db"
JSONL_SRC="${ARTIFACTS_ROOT}/paper-trades.jsonl"

TIMESTAMP="$(date -u +%Y-%m-%dT%H%M%S)"
DB_DST="${BACKUP_DIR}/paper-trades-${TIMESTAMP}.db"
JSONL_DST="${BACKUP_DIR}/paper-trades-${TIMESTAMP}.jsonl"

# ── Helpers ───────────────────────────────────────────────────────────────────
log() { echo "[backup] $(date -u +%Y-%m-%dT%H:%M:%SZ)  $*"; }

# ── Setup ─────────────────────────────────────────────────────────────────────
mkdir -p "${BACKUP_DIR}"
log "backup dir: ${BACKUP_DIR}"
log "artifacts root: ${ARTIFACTS_ROOT}"

# ── SQLite backup ─────────────────────────────────────────────────────────────
if [[ ! -f "${DB_SRC}" ]]; then
    log "WARNING: DB not found (${DB_SRC}), skipping"
else
    sqlite3 "${DB_SRC}" ".backup '${DB_DST}'"
    log "DB backup OK: ${DB_DST}"
fi

# ── JSONL backup ──────────────────────────────────────────────────────────────
if [[ ! -f "${JSONL_SRC}" ]]; then
    log "WARNING: JSONL not found (${JSONL_SRC}), skipping"
else
    cp "${JSONL_SRC}" "${JSONL_DST}"
    log "JSONL backup OK: ${JSONL_DST}"
fi

# ── Prune old backups ─────────────────────────────────────────────────────────
PRUNED=0
while IFS= read -r -d '' old_file; do
    rm -f "${old_file}"
    log "pruned: ${old_file}"
    PRUNED=$(( PRUNED + 1 ))
done < <(find "${BACKUP_DIR}" -maxdepth 1 \
    \( -name 'paper-trades-*.db' -o -name 'paper-trades-*.jsonl' \) \
    -mtime "+${RETAIN_DAYS}" -print0)

log "pruned ${PRUNED} old backup file(s)"
log "done"
```

## Notes

- The systemd timer unit (`crypto-trader-backup.timer`) and service unit (`crypto-trader-backup.service`) are defined in `docs/superpowers/plans/2026-04-07-lightsail-deployment.md` and must exist on the server before this script is useful. The script itself lives at `/opt/crypto-trader/scripts/backup.sh` on the server (synced via rsync from `scripts/backup.sh` in the repo).
- `sqlite3 .backup` acquires a shared lock for the minimum time needed to copy pages and is safe while the daemon holds write transactions — no daemon stop is required.
- Backup filenames use UTC timestamps (`%Y-%m-%dT%H%M%S`) to avoid timezone ambiguity; `RETAIN_DAYS=7` uses `find -mtime` which is also UTC-based, so there is no off-by-one risk from Seoul timezone.
- `CT_ARTIFACTS_ROOT` must be exported in `/etc/crypto-trader/environment` on the Lightsail server; the `EnvironmentFile` directive in the service unit makes it available to the script at runtime.
