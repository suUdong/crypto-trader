## Risk And Gate Changes

### Macro sizing

Macro score/level/layer are now attached to runtime context. This makes macro
state available to sizing/gating logic without changing the paper-first
operating policy.

### Entry blackouts

Two independent blackout layers now coexist:

| Layer | Code path | Blocked window | Reason |
|---|---|---|---|
| KST night | `pipeline.py` | KST 23:00-07:59 | Defensive low-quality/off-hours gate |
| UTC morning-Korea | `RiskConfig.entry_blackout_utc_hours` | UTC 23:00-02:59 / KST 08:00-11:59 | Data-proven paper loss cluster |

Both downgrade BUY to HOLD rather than changing sizing.

### Symbol circuit breaker

Defaults:

- 3 losing closes in 48h disables the symbol.
- Mean `pnl_pct < -0.5%` across at least 5 trades in 48h disables the symbol.
- Disabled symbols cool down for 24h.
- State persists at `artifacts/symbol-circuit.json`.
- Events are written to `artifacts/circuit-breaker-events.jsonl` for
  fire-monitor collection.

### Live scaffold

Live mode requires:

- `paper_trading = false`.
- `LIVE_TRADING_ENABLED=true` or `CT_LIVE_TRADING_ENABLED=true`.
- Fresh `artifacts/live-confirmed.json`.
- Upbit credentials in env.
- Telegram configured.
- Live hard caps unchanged.
- Optional but recommended `live_dry_run = true` rehearsal before real capital.
- `scripts/preflight_live_check.py` clean result.
